# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

여러 플랫폼에서 발견한 영상, 게시물, 웹사이트를 저장하지만 나중에 다시 찾기 어려운 사용자. 영감과 참고자료를 모으고, 정리하고, 기억나는 말로 다시 찾는 일을 한다.

## Product Purpose

흩어진 콘텐츠를 하나의 공간에 모으고, AI로 내용을 분석해 정리하며, 정확한 제목이나 URL을 몰라도 자연어로 다시 찾게 한다.

## Positioning

단순한 북마크 목록이 아니라, 저장한 콘텐츠의 내용을 이해해 자동 분류하고 사용자가 기억하는 문장으로 다시 발견하게 하는 개인 디지털 아카이브.

## Capabilities and Constraints

- 랜딩페이지, 로그인, 회원가입까지 프론트엔드를 구현한다.
- 인증은 비밀번호 없이 네이버, 구글 소셜 로그인만 사용한다.
- 백엔드는 별도로 개발하며, 프론트엔드는 환경변수로 API 주소를 연결한다.
- 실제 사용자 수, 성과 지표, 가격, 고객사 등의 상업적 주장은 확정되지 않았으므로 만들지 않는다.

## Brand Commitments

- 제품명은 `줍줍 저장소`.
- 제공된 HTML 시안의 문구, 따뜻한 오렌지 포인트, 종이와 아카이브를 연상시키는 정체성을 유지한다.
- 큰 한글 헤드라인, 넓은 여백, 명확한 시각 계층, 제품을 즉시 이해시키는 시각물을 지속적인 디자인 원칙으로 삼는다.

## Evidence on Hand

- 랜딩페이지 HTML 시안: `/Users/minjun/Downloads/jupjup-landing (10).html`
- Hackle과 Toss 웹사이트 스크린샷 3장: 레이아웃과 완성도의 참고자료이며 사실이나 브랜드 자산으로 사용하지 않는다.
- Figma 웹사이트 레이아웃 자료: 시선 패턴, 크기와 무게, 명확한 정보 구조의 참고자료.

## Product Principles

- 저장은 빠르게, 정리는 자동으로, 다시 찾기는 자연스럽게 만든다.
- 제품의 가치를 추상적인 설명보다 실제 사용 장면으로 보여준다.
- 사용자가 다음 행동을 고민하지 않도록 단순한 흐름을 제공한다.
- 증명되지 않은 수치와 고객 주장을 만들지 않는다.

## Accessibility & Inclusion

키보드 탐색, 명확한 포커스, 충분한 대비, 신체 움직임 감소 설정, 모바일 화면을 기본 요구사항으로 다룬다.
